Particular calendars for this fork. Start at docs/proper/START-HERE.md.

The files under country/, institute/, diocese/, and apostolate/ are read by
DivinumOfficium::ParticularCalendar. Office lines still live in
../Kalendaria/. data.txt still names the version chain. occurrence() in
horascommon.pl still resolves a date against the temporal cycle.

A file under proposals/ is not read by layers(), ordo_note(), mass_file(),
or episcopal_collect_file(). The example there is not a real calendar.
